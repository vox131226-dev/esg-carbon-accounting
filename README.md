# China ESG Carbon Accounting Skill

中国化统一ESG与碳核算技能。

## 核心能力

- 企业温室气体盘查：Scope 1/2/3、GHG Protocol、ISO 14064-1
- 产品碳足迹：ISO 14067、ISO 14040/14044、LCA、BOM
- ESG/可持续发展报告：IFRS S1/S2、GRI、中国交易所规则适用性
- 中国碳市场：CEA、CCER、方法学适用性、项目评估和尽职调查
- 数据质量、证据链和审计复核

## 强制防错原则

1. 正式有效文件与征求意见稿严格分离。
2. 中国监管核算参数、企业Scope 2、产品碳足迹因子和CCER方法学参数不得混用。
3. 预测减排量、已登记项目、已核证减排量、已交易/已注销资产严格区分。
4. 中国项目优先使用适用的中国官方规则和因子。
5. 正式项目在出具结论前再次核验最新政策、方法学和因子版本。

该技能用于专业分析和报告辅助，不替代法定第三方审定、核查、认证或法律意见。
