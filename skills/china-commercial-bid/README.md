# China Commercial Bid Skill

中国商务标/资信标/资格标编制与终审技能。

## 聚焦范围
- 资格审查
- 资信与企业实力
- 类似业绩
- 财务、纳税、社保、信用
- 投标函、法人身份证明、授权委托书
- 中小企业等政策材料
- 商务条款响应与商务偏离
- 报价一致性与限价审查
- 服务/履约/质保等商务承诺
- 合同商务条款响应
- 投标保证金/保函
- 签字盖章、文件格式与电子提交
- 商务评分提分与废标风险审查

## 不负责
本技能不编写技术方案、施工组织设计或软件系统架构。若用户需要技术标，应调用独立技术标技能。

## 核心原则
先资格、再符合性、再商务评分、再报价一致性、最后做红队终审。任何资质、业绩、财务、证书、人员和价格均不得编造。
